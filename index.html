Why can't the page scan my folder automatically? For security, browsers never expose a drive's file list to a web page. A site must either be given files by you, or use the File System Access API (Chrome/Edge on localhost or HTTPS).
Two ways to build your library Keep permanent videos in videos/ and register them in the DEFAULT_LIBRARY list at the top of script.js. Files you import here are available for this session only; their watch progress is remembered by file name and size.

Tip: you can select several files at once. Supported: MP4, WebM, OGG, MOV, M4V and MKV (depends on your browser's codec support).
